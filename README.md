# Misi Tatabahasa Tahun 4
Permainan interaktif Bahasa Melayu Tahun 4 — Tatabahasa.

## Maklumat
- Guru: MUHAMAD SYAWALWAHED
- Sekolah: SK (P) JALAN YAHYA AWAL
- 20 soalan
- Nota tatabahasa
- Sistem markah dan nyawa
- Animasi/pergerakan CSS
- Bunyi maklum balas menggunakan Web Audio API
- Mesra telefon dan komputer

## GitHub Pages
1. Cipta repository baharu di GitHub, contohnya `misi-tatabahasa-tahun4`.
2. Muat naik semua fail dalam folder ini.
3. Pergi ke **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Simpan. Pautan akan berbentuk:
   `https://NAMA-ANDA.github.io/misi-tatabahasa-tahun4/`

Tiada server diperlukan.
